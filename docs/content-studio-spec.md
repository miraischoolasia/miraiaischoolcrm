# Content Studio（行销内容工厂）规格 v1 — 2026-10-21

老板说「开始」。负责部门：**② 自动化 + AI**（功能先做；画面最后由 ⑦ 美化，照「功能先、UI 最后」的规矩）。

## 一句话
管理员给资料 → AI 先出「计划表」→ 管理员确认 → AI 出海报 / Carousel + 文案 → 管理员审核 → 员工到素材库「领取」去发自己的社交媒体。

## 老板已决定
| # | 问题 | 老板的答案 |
|---|---|---|
| 1 | 海报上的字 | **A：AI 直接把字画进图里**（所以每张要有「重新生成」，审核一定要有） |
| 2 | 员工领取前要不要审核 | **要**：管理员按「通过」后员工才看得到 |
| 3 | 一份可以几个人领 | **C**：每份最多 N 人（学校设定，默认 3），**所有人都看得到已领几人 / 上限几人**（例如「2/3 已领」） |
| 4 | 尺寸 | 全部可选：1:1、4:5、9:16（Story）、3:4（小红书） |
| 5 | 文案语言 | **马来西亚道地华文**（口语、亲切，不是大陆腔或台湾腔） |
| 6 | AI | 最终用 ChatGPT（OpenAI API）；**现在先用 Gemini 测试**。供应商是设定里的一个开关，换的时候不用改流程 |
| 7 | 逻辑 | 不是一直聊天：填表 → 计划表 → 确定后才画图；只有「改某一张」时用对话框 |
| 8 | 速度 | 同时画多张、背景执行、画好一张出现一张、做完通知；有「草稿画质」先挑，挑中的再出「高画质」 |

## 三层资料（AI 靠这些决定画什么）
1. **学校品牌**（设一次）：沿用 Brand 设定的 logo、颜色、吉祥物；另加：说话语气、禁用字眼、每张一定要有的资料（WhatsApp 号码、网址）。
2. **风格库 + 角度库**（管理员可加、改、隐藏，照白标规矩每校一份，先放 Mirai/EduHero 默认几个）：
   - 风格卡：名字、文字描述、**参考图（可多张）**。
   - 角度卡：名字、说明、1–2 个标题例子（例：家长痛点、成绩见证、限时优惠、老师介绍）。
3. **这次活动（素材包 Brief）**：推什么、重点（价钱/日期/年龄）、对象、行动呼吁；上传 PDF（读出文字）、图片；选风格、角度、数量、尺寸、类型（单张 / Carousel 几页 / 只要文案）。

## 流程
1. 建 Brief。
2. **计划表**（文字模型，几秒）：N 行，每行 = 风格、角度、大标题、副标题、海报上的其他字、文案、画面描述、尺寸。管理员可改字、删行、「再想几个」。
3. 按「确定」→ **画图**（图片模型）：背景排队、可同时几张；先草稿画质。
4. 每张图：👍 / 👎、「重新生成」、对话框改图（「标题大一点」「换蓝色」）、「出高画质」。
5. **审核**：通过 / 不通过。通过的进素材库。
6. **素材库**（员工看到的）：按活动、风格、角度、平台、尺寸筛选；每张显示「已领 x / 上限 y」；按「领取」→ 下载图片（Carousel 下载全部页）+ 一键复制文案；领满了显示「已领完」。系统记录谁、何时领了哪一份。
7. 👍 的作品自动加进该风格的参考图（越用越准）。

## 权限（新页面的勾选，照现有 has_permission 写法）
- **Content Studio**：建 Brief、生成、审核（管理员 / 行销）。
- **Content Library**：看素材库、领取（一般员工）。

## 技术方向（给 ② 参考，照现有写法）
- Supabase edge function（例如 `content-generate`），钥匙放 secrets，不印出来；Gemini 钥匙照 `ai-draft` 的读法。图片模型先用 Gemini 能出图的模型，之后加 OpenAI 图片模型；文字模型同样可切换。
- 图片存 Supabase Storage；资料表大概是 briefs / plan_items / assets / claims + 风格、角度两张设定表；每校一份。
- 每天生成上限（学校设定），防止误按烧钱；每次记录用了多少张。
- 参考的开源做法：simplicio-marketing-engine（Apache-2.0，流程和供应商开关）、n8n 的「文案 AI + 画图指令 AI + 审核」流程。只借设计和提示词写法，不另外装系统。

## 分期
| 期 | 内容 |
|---|---|
| 1 | 品牌补充设定、风格库/角度库、Brief（含 PDF 读字）、**计划表 + 文案**、审核、素材库 + 领取（上限 + 已领人数）、权限 |
| 2 | 画图（单张 + Carousel）、草稿/高画质、重新生成、对话改图、👍 变参考图、背景排队 + 通知 |
